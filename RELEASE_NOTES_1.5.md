# Modulez Player 1.5

XMP Module Player is now **Modulez Player**.

In memory of modulez.org (2000-2013): http://misc.yero.org/modulez/

- New Modulez application icon, also available as a separate PNG download.
- Updated window title, About tab, tray menu, preferences text, and IRC greeting.
- New Modulez Player desktop entry and AppImage filename.
- All six playback engines retained, including UADE seeking and WAV export.
- Bundled UADE runtime and default MIDI SoundFont with its license.
- Existing preferences and SoundFont settings carry over.

AppImage tested locally for playback, seeking, and WAV export.
