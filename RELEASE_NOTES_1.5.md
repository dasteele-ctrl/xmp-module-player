# Modulez Player 1.5

XMP Module Player is now **Modulez Player**.

- New Modulez application icon, also provided as a separate PNG download.
- Updated window title, About tab, tray menu, preferences text, and IRC greeting.
- New Modulez Player desktop entry and AppImage filename.
- Existing playback engines, UADE seeking/WAV export, and bundled SoundFont retained.
- Existing configuration paths preserved so preferences and SoundFont settings carry over.

This branch is for local testing. Do not replace the published 1.4.3 AppImage.
Before publishing 1.5, test all six engines, tray/menu controls, an existing
settings profile, AppImage integration, and a clean exit. Update the README
development notice and screenshot when the 1.5 release is ready.
