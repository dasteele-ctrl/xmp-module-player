# Modulez Player 1.8.1

Browse Music brings Modland, The Mod Archive and Amiga Music Preservation (AMP) into the player. Use **Add site…** to save a personal archive alongside them.

- Click a track download to add it to the playlist and start playback. Drag a download link onto the player to queue it while the current track plays.
- Modland opens with shortcuts for MOD, XM, S3M and IT, plus access to the full archive. The downloader recognizes Archimedes Tracker MUSX and can probe unfamiliar Modland files with libxmp.
- Modland directories use a dark theme. The Mod Archive uses larger text and a charcoal layout that fills the browser pane.
- AMP downloads stay in the embedded browser session. The player can unpack gzip-compressed tracks.
- The About tribute includes **Visit Modulez in 2012**, which opens the archived music page in the default browser.
