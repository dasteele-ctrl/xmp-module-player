# Modulez Player 1.7.7

## New Features
- Open audio and tracker modules directly from HTTP/HTTPS URLs.
- Download and play music from ModArchive, Modland, and other online archives.
- Download cancellation and error handling.
- WAV audio export.
- Support for .psid and .rsid filename extensions.
- Automatic decoding of URL-encoded filenames.

## Interface Improvements
- Redesigned player control layout.
- Equal-width playback controls.
- Expanded volume slider.
- Improved playlist toolbar positioning.
- Rounded buttons and notebook tabs.

## Technical Improvements
- Native HTTP/HTTPS downloading using libsoup 3.0.
- Persistent storage of downloaded music.
- No additional direct library dependencies.
- No API key required for public direct download URLs.
