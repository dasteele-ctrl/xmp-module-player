# Modulez Player 1.7.5 — Release Notes

## What's New

- Enhanced the About tab with visual refinements.
- Improved the overall presentation of application information.
- Minor interface polish and maintenance.

## Playback

All six playback engines remain unchanged.

## AppImage Updates

The built-in AppImage update system introduced in version 1.7.4 continues to be supported.

Users can check for updates from the About tab and download new releases without interrupting music playback.

## Compatibility

Linux x86_64. Built and tested on Linux Mint 22.3 XFCE.
